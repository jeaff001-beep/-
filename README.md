# 雙向語音翻譯器

網站與手機安裝入口：https://jeaff001-beep.github.io/-/

中文可與英文、日文、韓文雙向語音翻譯。選好對方語言後，按對應區塊的麥克風說話；翻譯完成時會自動朗讀，也可以按播放鍵再聽一次。

## 安裝到手機主畫面

- Android：使用 Chrome 開啟網站，點選瀏覽器選單中的「安裝應用程式」或「新增至主畫面」。
- iPhone：使用 Safari 開啟網站，點選分享，再選「加入主畫面」。

語音辨識、翻譯與語音播放依賴手機瀏覽器的支援。使用語音辨識與翻譯時需要網路連線及麥克風權限；離線時仍可開啟頁面，但無法翻譯。

## 本機執行

在儲存庫目錄執行 `python3 -m http.server 8765`，再用瀏覽器開啟 `http://127.0.0.1:8765/`。
